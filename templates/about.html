About SecureStego

Protecting confidential communication through image steganography and encryption.

What is SecureStego?

SecureStego is a web-based image steganography tool designed to hide confidential messages inside digital images. It combines image steganography with encryption to provide an additional layer of privacy.


What is Image Steganography?

Image steganography is a technique used to hide secret information inside digital images. Unlike ordinary encryption, which makes information unreadable, steganography attempts to conceal the existence of the information itself.


How Does SecureStego Work?

SecureStego uses the Least Significant Bit (LSB) technique to hide encrypted messages inside image pixels.


Step 1 - Message Encryption:
The secret message is encrypted using AES-256-GCM with a password-derived key.


Step 2 - Data Hiding:
The encrypted data is converted into binary and hidden inside the least significant bits of image pixels.


Step 3 - Message Extraction:
The website reads the hidden binary data from the encoded image and decrypts it using the correct password.


Security Features

• AES-256-GCM authenticated encryption
• PBKDF2-HMAC-SHA256 password-based key derivation
• Random salt and nonce generation
• LSB image steganography
• Image format and file size validation
• Password strength validation
• Secure file download validation


Technologies Used

Frontend: HTML, CSS and JavaScript
Backend: Python and Flask
Image Processing: Pillow
Encryption: Python Cryptography Library


Important Security Information

SecureStego provides an additional layer of privacy through encryption and steganography. However, image resizing, compression or editing may damage hidden data. Users should keep the original encoded PNG image and remember their password.
